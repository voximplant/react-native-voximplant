# @voximplant/react-native-shared

Shared types and utilities for the [Voximplant React Native SDK](https://github.com/voximplant/react-native-voximplant).

[`@voximplant/react-native-core`](https://www.npmjs.com/package/@voximplant/react-native-core) and [`@voximplant/react-native-calls`](https://www.npmjs.com/package/@voximplant/react-native-calls) install this package for you. Add it yourself only when application code imports `@voximplant/react-native-shared` directly.

## Requirements

| Requirement | Minimum |
| --- | --- |
| react | ^19.2.0 |
| react-native | >=0.77.0 <1.0.0 |

## Install

```bash
npm install @voximplant/react-native-shared
```

This package is JavaScript only. It has no native module.
